# Slidesfly Agent Skill

This directory is the public, versioned source for the official Slidesfly Skill.

Install it with:

```bash
npx skills add rare/slidesfly-integrations --skill slidesfly
```

The hosted copy at <https://slidesfly.com/SKILL.md> remains the canonical distribution endpoint
for `slidesfly install`. Both copies use the version marker in `SKILL.md` and must be reviewed
together before a release.
