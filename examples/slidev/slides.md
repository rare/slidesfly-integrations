# Slidev on Slidesfly

Build a static presentation, package its assets, and publish one stable reader URL.

---

## Build locally

```bash
npm run build
```

The output must contain `dist/index.html`.

---

## Test before sharing

- Keyboard and touch navigation
- Fonts, images, and code highlighting
- No browser-storage dependency
- No remote runtime scripts
